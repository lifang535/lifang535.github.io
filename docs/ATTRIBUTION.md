# Layout and asset attribution

The site is an original static HTML/CSS/JavaScript implementation inspired by the sidebar layout and blue-gray styling of [Xinyu Xiao's homepage](https://alex4210987.github.io/). The reference site's personal text, portrait, CV, and photographs are not included.

`assets/avatar.svg` and `assets/favicon.svg` are original lettermark graphics for Mingfang Ji. The avatar is a monogram, not a photograph.
